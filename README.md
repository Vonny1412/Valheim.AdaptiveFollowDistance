**Multiplayer Compatibility**

AdaptiveFollowDistance does not require Jötunn and does not enforce mod synchronization.

For consistent behavior in multiplayer, the mod should be installed on the server and all connected clients, using the same configuration.

The mod may still work when installed on only some participants, but follow distances can differ depending on which instance controls the creature's AI.
